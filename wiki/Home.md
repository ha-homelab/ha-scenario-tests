# HA Scenario Tests wiki

This checked-in wiki is versioned with the software; publishing it to a GitHub wiki is a separate operation.

Start with [installation](https://github.com/ha-homelab/ha-scenario-tests/blob/main/docs/install.md), then [scenario v1](https://github.com/ha-homelab/ha-scenario-tests/blob/main/docs/scenarios.md). Run the four files in `examples/`. Read [limits](https://github.com/ha-homelab/ha-scenario-tests/blob/main/docs/limits.md) before interpreting a passing report. A pass describes synthetic service dispatch by a real HA engine, never a physical device.
