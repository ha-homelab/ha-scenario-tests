# Ограничения и доказательства

Проверяется ограниченный набор настоящих триггеров, условий, таймеров, reload и отправки действий HA. Входные состояния и исполнители синтетические. Тест не доказывает работу протокола, ток, точность датчика, физическое состояние реле, безопасность или совместимость произвольной конфигурации.

Часы — настоящее монотонное время. Используются короткие паузы с запасом планирования. Внутренние delay-методы HA не подменяются, таймеры рабочего дома не переписываются. DST, календарное время, полный перезапуск процесса и сохранение Recorder в v1 не входят. Reload не равен restart.

Вход не содержит исполняемых шаблонов и конфигурации интеграций. Каждый процесс имеет временную папку, сокращённую среду и общий audit guard. Это блокирует случайный Python I/O в допустимом пути, но не является защитой от враждебного кода. Интерпретатор, зависимости и хост считаются доверенными. Docker --network none добавляет сетевую границу, но не доказывает поведение оборудования.

Публичный отчёт должен содержать синтетические данные. История состояний раскрывает привычки и присутствие даже без токенов. Рисунки синтетические; генерация: `python scripts/render_diagrams.py`.

В [validation](validation.ru.md) указаны реально выполненные проверки. Наличие Dockerfile само по себе не означает, что контейнер испытан на всех платформах.
